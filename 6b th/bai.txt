📌 Yêu cầu:

Tạo form:

Username
Password
Nhập lại password
Email

👉 Validate:

Không để trống
Password ≥ 6 ký tự
Password nhập lại phải giống

👉 AJAX gửi dữ liệu → PHP kiểm tra:

Nếu username đã tồn tại → báo lỗi
Nếu ok → lưu DB

👉 DB:

CREATE DATABASE accountDB;
CREATE TABLE users (
    username VARCHAR(50),
    password VARCHAR(50),
    email VARCHAR(100)
);
